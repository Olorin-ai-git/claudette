# Claudette vs. First-Party Claude Apps

A comprehensive research, analysis, and comparison of what **Claudette** offers
versus what **Anthropic's own first-party Claude apps** offer for driving Claude
Code from a phone, tablet, or browser.

> **Scope & dates.** Claudette details are drawn from this repository
> (`README.md`, `STATUS_ANALYSIS.md`, and the Swift/TypeScript source). First-party
> details are drawn from Anthropic's official documentation at `code.claude.com`
> and `support.claude.com` as of **June 2026**. Both products are moving targets;
> the first-party "Claude Code on the web," "Remote Control," and "Dispatch"
> features are in research preview and evolve frequently.

---

## 1. TL;DR

| | **Claudette** | **First-party Claude apps** |
|---|---|---|
| **What it is** | A third-party native mobile app (iOS/Android) that is an **SSH remote control** for Claude Code running on *your own Mac* | Anthropic's official Claude mobile/desktop/web apps + Claude Code, with three ways to reach a session remotely: **Remote Control**, **Dispatch**, and **Claude Code on the web** |
| **Where Claude runs** | On your Mac (you own the box, the keys, the compute) | Either on your machine (Remote Control / Dispatch / Cowork) **or** in Anthropic's cloud VM (Claude Code on the web) |
| **Transport** | Direct SSH (or Olorin's WebSocket relay) — no Anthropic account, no Anthropic infra in the path | Outbound HTTPS to the Anthropic API; the phone/web is "just a window" into the session |
| **Account/cost** | No accounts, no backend, no telemetry; you pay only for your own Claude usage | Requires a claude.ai subscription (Pro/Max/Team/Enterprise); shares your existing rate limits |
| **Maturity** | v2.0, TestFlight + Google Play, 0% test coverage, no CI | GA mobile/desktop apps; Remote Control / web in research preview, shipping rapidly |

**The headline:** Claudette pioneered "drive Claude Code from your phone." Anthropic
has since shipped **first-party features that overlap heavily** — Remote Control
(drive a local session from the Claude app), Dispatch (message a task to your
desktop), and Claude Code on the web (cloud sandbox). Claudette's durable
advantages are now narrower but real: **raw terminal access, zero-abstraction
control, no-account/no-cloud privacy, multi-tab tmux, and Mac-management
conveniences** (Bonjour, Wake-on-LAN, SFTP). The first-party apps win on
**zero-setup cloud execution, native push, polished UX, official support, and
deep platform integration**.

## 2. What each product actually is

### 2.1 Claudette

Claudette (by Gil Klainert / Olorin-ai-git, MIT-licensed) bills itself as
*"the mobile workstation for Claude Code — 35+ power tools, raw terminal access,
zero abstraction."* Architecturally it is a **purpose-built SSH/tmux client** that
connects from your phone to your Mac and runs Claude Code there:

```
+-------------------+      SSH / relay      +-------------------+
|  Claudette        | --------------------- |  Your Mac         |
|  (iOS / Android)  |                       |   tmux  └ claude  |
+-------------------+                       +-------------------+
```

- **No cloud, no accounts, no backend.** SSH goes directly device → Mac, or via
  the optional Olorin Relay WebSocket bridge for off-LAN access.
- iOS app is Swift/SwiftUI (MVVM + service layer; ~90 files, 19+ services).
- A companion TypeScript CLI (`npx claudette-setup`) automates Mac prep and
  QR-code pairing.
- Android lives in a separate repo.

### 2.2 The first-party landscape

"First-party Claude apps" is not one thing — it's a family. The relevant pieces
for this comparison:

| First-party surface | What it is | Where Claude runs |
|---|---|---|
| **Claude mobile app** (iOS/Android) | The official chat app; also the client for Remote Control, Dispatch, and Claude Code on the web sessions | n/a (client) |
| **Claude desktop app** (Mac/Win) | Native app with Chat, **Cowork** (agentic local tasks in an isolated VM), Claude Code, MCP desktop extensions | Your computer |
| **Claude Code CLI** | The agentic coding tool itself | Your machine |
| **Remote Control** | Drive a *local* Claude Code session from claude.ai/code or the mobile app | Your machine |
| **Dispatch** | Message a task from the mobile app → spawns a Desktop session on your machine | Your machine (Desktop) |
| **Claude Code on the web** | Kick off tasks that run in an **Anthropic-managed cloud VM** | Anthropic cloud |

The two first-party features that compete most directly with Claudette are
**Remote Control** (same idea: phone → your own machine) and **Claude Code on the
web** (the no-setup cloud alternative). This document is the environment you are
reading it in: it was generated by Claude Code on the web.

## 3. Architecture & trust model (the core difference)

This is the most important axis, because everything else follows from it.

| Dimension | **Claudette** | **Remote Control** (first-party, local) | **Claude Code on the web** (first-party, cloud) |
|---|---|---|---|
| Compute location | Your Mac | Your machine | Anthropic-managed VM (4 vCPU, 16 GB RAM, 30 GB disk) |
| Connection | SSH (direct) or Olorin Relay WS | Outbound HTTPS to Anthropic API; no inbound ports | Runs in cloud; you connect to claude.ai |
| In the data path | You ↔ your Mac only (or Olorin's relay) | Anthropic API relays messages | Anthropic infra runs the code |
| Account required | **None** | claude.ai Pro/Max/Team/Ent | claude.ai Pro/Max/Team/Ent |
| Credentials | Your SSH keys (Ed25519, on-device Keychain) | Short-lived scoped Anthropic tokens | Scoped tokens; **git creds never enter the sandbox** (proxy) |
| Telemetry | None (no network except SSH/relay) | Standard Anthropic API traffic | Standard Anthropic API + cloud session retention |
| Your local env (files, MCP, tools) | Fully available — it *is* your Mac | Fully available — runs locally | **Not** available unless committed to the repo |
| Works offline from Anthropic? | Yes (LAN SSH needs no Anthropic at all, beyond Claude's own API calls) | No | No |

**Reading this table:**

- **Claudette and Remote Control are the same *shape*** — phone is a window onto a
  Claude Code session on your own hardware. The difference is the pipe: Claudette
  uses **SSH/your-own-relay with no Anthropic account in the loop**, while Remote
  Control routes through the **Anthropic API with a subscription**.
- **Claude Code on the web is a different animal**: zero local setup, runs in the
  cloud, parallelizable, but sandboxed away from your local filesystem/MCP and
  gated behind a subscription + GitHub.

## 4. Feature-by-feature comparison

### 4.1 Terminal & interaction model

| Capability | Claudette | First-party |
|---|---|---|
| Raw SSH terminal emulation | ✅ Full PTY, extended keyboard row (Esc, Tab, Ctrl+C, Ctrl+T, pipe, brackets) | ⚠️ Remote Control/web give a **chat-style** interface, not a raw shell. The terminal lives on your machine via the CLI |
| Structured/chat view of tool use | ✅ "Structured Mode" toggles between raw terminal and a streaming conversation view | ✅ Native — the web/mobile UI *is* a structured conversation with diffs |
| Run arbitrary shell commands by hand | ✅ It's a real terminal — anything | ⚠️ Only what Claude runs; remote surfaces expose text commands, not a free shell |
| Multi-tab sessions | ✅ Multiple tabs, each its own tmux session | ✅ Multiple cloud sessions in parallel (web); Remote Control server mode supports many sessions (default capacity 32) |
| Session persistence across backgrounding | ✅ tmux-wrapped, auto-reconnect | ✅ Cloud sessions persist server-side; Remote Control reconnects but **dies if the local process stops** |
| `@`-autocomplete of local file paths | ❌ (terminal only) | ✅ Remote Control autocompletes from your local project |

**Verdict:** Claudette wins decisively on **raw terminal / zero-abstraction**. If
you want a real shell in your pocket, Claudette is unique. First-party deliberately
abstracts the terminal into a chat+diff UI.

### 4.2 Claude Code feature surface

| Capability | Claudette | First-party |
|---|---|---|
| Commands / Skills / Agents browser | ✅ Browse & trigger your toolkit with one tap | ✅ Native; repo `.claude/skills`, `/agents`, `/commands` load automatically (web) |
| Hooks configuration from the app | ✅ Edit PreToolUse/PostToolUse/Notification/Stop in-app | ⚠️ Hooks come from repo `.claude/settings.json`; not edited from the phone UI |
| Subagents / agent teams | ✅ "Agent Visualizer" renders the agent tree live | ✅ Subagents native; agent teams via `CLAUDE_CODE_EXPERIMENTAL_AGENT_TEAMS=1` |
| MCP servers | ⚠️ Whatever your Mac has (you run them) | ✅ Repo `.mcp.json` (web); **local MCP fully available** (Remote Control); cloud routes MCP connectors through Anthropic |
| Context window & cost monitor | ✅ Live token gauge, threshold warnings, **live cost tracking** | ⚠️ `/context`, `/usage`, `/compact` available; less of a dedicated always-on gauge |
| Live task monitor | ✅ Pending/in-progress/done with progress bar | ✅ `/tasks`, session list, diff indicators |
| CLAUDE.md viewer | ✅ With token estimate & char count | ➖ Read in-session |
| Prompt snippets drawer | ✅ Categorized (refactor/debug/git…) | ➖ No direct equivalent (you can use custom commands) |
| Auto-fix PRs (CI + review comments) | ❌ | ✅ First-party **Auto-fix** subscribes to GitHub webhooks and pushes fixes |
| Plan-locally / execute-in-cloud, ultraplan, ultrareview | ❌ (no cloud tier) | ✅ `--remote`, `--teleport`, ultraplan, ultrareview, routines/scheduled tasks |

**Verdict:** Roughly even on the *local* Claude Code surface, with Claudette
offering nicer **purpose-built mobile dashboards** (cost gauge, agent visualizer,
snippet drawer, in-app hook editor). First-party wins on **cloud-native workflows**
(parallel cloud tasks, auto-fix, teleport, routines) that Claudette structurally
cannot do because it has no cloud tier.

### 4.3 Voice & accessibility

| Capability | Claudette | First-party |
|---|---|---|
| Voice **input** (dictate prompts) | ✅ On-device speech recognition overlay | ✅ Voice Mode (multilingual, push-to-talk, free for all as of early 2026) |
| Voice **output** | ✅ **AI vocal summary** — reads a concise summary aloud when a task finishes | ✅ 5 voices (Buttery, Airy, Mellow, Glassy, Rounded); conversational TTS |
| Push notifications | ⚠️ App-level "Notification" hook + permission alerts; no documented native push service | ✅ **Native mobile push** ("push when Claude decides" / "push when action required") via Remote Control |

**Verdict:** First-party voice is more general-purpose and polished; Claudette's
**vocal task summary** is a genuinely nice, purpose-built touch. First-party wins
clearly on **real push notifications**, which Claudette lacks as a managed service.

### 4.4 Infrastructure, networking & Mac management

| Capability | Claudette | First-party |
|---|---|---|
| Reach machine from anywhere w/o port-forwarding | ✅ Olorin Relay (managed WS) **or** Tailscale/VPN | ✅ Anthropic API relay (no inbound ports at all) |
| LAN auto-discovery (Bonjour/mDNS) | ✅ | ❌ |
| Wake-on-LAN | ✅ Wake your Mac before connecting | ❌ |
| SFTP file browser + remote editor | ✅ Browse/edit any remote file over SFTP | ⚠️ Edit via Claude/diff view; cloud has no access to local FS |
| Host-key TOFU pinning | ✅ Trust-on-first-use, warns on change | n/a (TLS to Anthropic) |
| QR pairing | ✅ `npx claudette-setup` QR | ✅ Remote Control shows a QR to open the session |
| Zero setup on the machine | ❌ Needs SSH + tmux on the Mac | ✅ Cloud needs nothing local; Remote Control needs only the CLI |
| Repos you haven't cloned / cloud parallelism | ❌ | ✅ Claude Code on the web clones from GitHub and runs N tasks in parallel |

**Verdict:** Claudette is a **better Mac-management tool** (Bonjour, WoL, SFTP,
host-key pinning) because it's a real SSH client. First-party wins on
**zero-setup reach** and **cloud parallelism**.

### 4.5 Platform, ecosystem & support

| Dimension | Claudette | First-party |
|---|---|---|
| Platforms | iOS/iPadOS (TestFlight; App Store pending), Android (Play) | iOS, Android, macOS, Windows, web, VS Code/JetBrains |
| Source available | ✅ MIT, fully auditable | ❌ Closed (CLI is distributed, not open) |
| Official support / SLA | ❌ Community/issues | ✅ Anthropic support, enterprise SLAs, admin controls |
| Tied to Anthropic billing | ❌ | ✅ Subscription-gated |
| Update cadence / feature velocity | Small indie project (17 commits, 1 PR at last analysis) | Very high — shipping new remote features monthly |
| Enterprise controls (ZDR, IP allowlist, admin toggles) | ❌ | ✅ Full enterprise governance |

## 5. Where Claudette genuinely wins

1. **Raw terminal, zero abstraction.** A real PTY with an extended keyboard. No
   first-party surface gives you an actual shell on your phone. For power users
   who want to `git rebase`, tail logs, or run anything, this is unmatched.
2. **No account, no cloud, no telemetry.** Nothing touches Anthropic's infra
   except Claude's own model calls. Appealing for privacy-sensitive, air-gapped-ish,
   or "I don't want a subscription dependency" users. Fully open-source and auditable.
3. **Mac-management niceties:** Bonjour discovery, Wake-on-LAN, SFTP browser/editor,
   TOFU host-key pinning — it's a capable general SSH client, not only a Claude tool.
4. **Purpose-built mobile dashboards:** live cost/token gauge, agent-tree
   visualizer, categorized snippet drawer, in-app hook editor, CLAUDE.md viewer.
5. **Multi-tab tmux** with survive-backgrounding persistence, independent of any
   Anthropic-side session lifecycle.
6. **Bring-your-own-transport:** works over plain LAN SSH, Tailscale, VPN, port
   forward, or the optional relay — your choice, no lock-in.

## 6. Where first-party wins

1. **Zero-setup cloud execution.** Claude Code on the web needs nothing on a local
   machine — run tasks (even on repos you haven't cloned) from any browser/phone,
   in parallel, in isolated cloud VMs with pre-installed toolchains.
2. **Native push notifications** — proactive and action-required pushes; Claudette
   has no equivalent managed push.
3. **First-party Remote Control / Dispatch** already deliver the "drive my machine
   from my phone" core, officially supported, with QR pairing and auto-reconnect.
4. **Cloud-only superpowers:** Auto-fix PRs (CI + review-comment webhooks),
   `--teleport` between web and terminal, ultraplan/ultrareview, routines and
   scheduled tasks, Slack integration.
5. **Polished, integrated UX** across iOS/Android/desktop/web/IDE, plus camera,
   widgets, Siri Shortcuts, and OS integrations on the chat app.
6. **Enterprise governance & support:** admin toggles, IP allowlisting, Zero Data
   Retention, scoped credential proxies, official SLAs.
7. **Security model for cloud:** git credentials never enter the sandbox; a GitHub
   proxy restricts pushes to the working branch; per-environment network allowlists.

## 7. The strategic picture

When Claudette launched, "use Claude Code from your phone" was a gap Anthropic
hadn't filled — Claudette was the answer. As of mid-2026, Anthropic has shipped
**three first-party answers** to that exact need:

- **Remote Control** — phone/web drives a local CLI/VS Code session. *Direct
  overlap with Claudette's core value prop*, but subscription-gated and routed
  through Anthropic.
- **Dispatch** — message a task from the mobile app; it spawns a Desktop session.
- **Claude Code on the web** — the cloud option Claudette can't match.

This compresses Claudette's moat to the things first-party deliberately **won't**
do:

- A **real terminal** (Anthropic chose a chat/diff abstraction on purpose).
- **No Anthropic account / no cloud / open source** (a privacy and independence
  stance Anthropic structurally can't offer for its own products).
- **General SSH/Mac-management** utility beyond Claude (Bonjour, WoL, SFTP).

### Recommendation by user type

| If you are… | Best fit |
|---|---|
| A terminal power user who wants a real shell on mobile | **Claudette** |
| Privacy/independence-focused, no-subscription, open-source preference | **Claudette** |
| Managing a Mac over SSH (discovery, WoL, SFTP) as well as Claude | **Claudette** |
| Want zero local setup / run tasks from anywhere / parallel cloud jobs | **Claude Code on the web** |
| Already pay for Claude and want official, supported phone control of your machine | **Remote Control / Dispatch** |
| Need push notifications, auto-fix PRs, teleport, routines, enterprise controls | **First-party** |
| Want the most polished, integrated, supported experience | **First-party** |

### Where Claudette could differentiate going forward

- Lean **harder into the terminal/SSH identity** first-party won't replicate
  (multi-host fleets, port forwarding, tmux power features, log tailing).
- **Interoperate** rather than compete: let Claudette attach to a `claude
  remote-control` server or surface Claude Code on the web sessions, becoming the
  best *mobile client* for both local and cloud Claude.
- Close obvious gaps: **native push**, automated tests/CI (currently 0% coverage,
  no CI), and feature-parity tracking between iOS and Android.
